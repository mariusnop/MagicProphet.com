# MagicProphet — Feedback & Roadmap

Your companion for Magic: The Gathering. Card search in plain language, price forecasts, collection management, camera card scanning, and combo discovery for new sets.

This is where you can **share feedback**, **request features**, and **see what's coming next**.

The app itself lives at **[magicprophet.com](https://magicprophet.com)**. The v1.0.0 public release lands **2026-08-30**.

## Reading the labels

| Label | Meaning |
|---|---|
| (none) | Received, not triaged yet |
| `accepted` | Confirmed and on the roadmap |
| `in-progress` | Currently being built |
| `shipping-soon` | In testing, lands in the next release |
| `wontfix` | We decided not to build this, the issue says why |
| (closed) | Live in the app, the closing comment names the version |

`area:*` labels say which part of the app an issue belongs to. `from-app` means it came in through the in-app feedback button.

---

## Status Updates

Every shipped feature gets a closing comment naming the version it went live in. Watch this repo to get notified when your feedback is addressed.
